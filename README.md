# 🎯 Python Quiz Game

A command-line quiz game built with **Python** and **Object-Oriented Programming (OOP)**.

Test your knowledge across three difficulty levels and see how high you can score!

---

## ✨ Features

- 🟢 **Easy Mode** — Beginner-friendly questions
- 🟠 **Hard Mode** — More challenging questions
- 🔴 **Extra Hard Mode** — Advanced questions
- 🔤 **A/B/C/D Answer Selection**
- 🏆 **Real-time Score Tracking**
- 📊 **Final Score Display**
- 🧩 **60 Questions** across all difficulty levels
- 🏗️ **Object-Oriented Programming**
- 📁 Separate modules for quiz logic, questions, and data

---

## 🛠️ Technologies Used

- **Python 3**
- **Object-Oriented Programming (OOP)**
- Python Lists & Dictionaries
- Loops & Conditional Statements
- Functions & Classes
- Modules & Imports

## 🎮 How to Play

### 1. Start the game

Run:

```bash
python main.py
```

### 2. Choose your difficulty

```text
Choose your difficulty:
1. Easy
2. Hard
3. Extra Hard

Enter your choice:
```

### 3. Answer the questions

Choose one of the four options:

```text
1. What is the capital of India?

A. Mumbai
B. Delhi
C. Kolkata
D. Chennai

Answer: B
```

### 4. Check your score

The game keeps track of your score as you progress and displays your final score when the quiz ends.
